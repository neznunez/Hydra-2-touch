# TouchDesigner

1. Abra o **Hydra 2 Touch** e execute um código Hydra.
2. No TouchDesigner, crie um **Spout In TOP**.
3. Em `Sender Name`, selecione **Hydra 2 Touch**.
4. Use a saída do TOP no seu projeto.

A transmissão é local, pela GPU, em 1920 × 1080 e 60 fps. O editor continua visível no aplicativo, mas a saída Spout contém apenas o visual Hydra.
